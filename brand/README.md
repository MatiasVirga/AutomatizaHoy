# Marca — exploraciones

Esta carpeta no forma parte del sitio. Guarda material de trabajo sobre el logo.

| Archivo | Qué es |
|---|---|
| `actual-isotipo.png` | Recorte del isotipo que usás hoy (A + flecha de flujo) |
| `comparativa.png` | Hoja comparativa: tres direcciones nuevas, en claro, en oscuro y a tamaño chico |
| `opcion-1.svg` | A sólida + flecha roja como travesaño, travesaño oscuro |
| `opcion-2.svg` | A sólida + travesaño y flecha rojos de una sola pieza |
| `opcion-3.svg` | Variante de flecha más fina |
| `icono-oscuro.svg` | Prueba de icono de app (fondo oscuro, A blanca, flecha roja) |

Son exploraciones geométricas hechas a mano en SVG, no un rediseño terminado. Ninguna reemplaza
todavía al isotipo actual: sirven para comparar direcciones antes de decidir.

Los SVG se abren en cualquier navegador o en Figma/Illustrator y no dependen de tipografías.
